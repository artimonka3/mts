# Этап 7 — результат и граница анализа

**Статус: готово в ручном/демо-режиме.** `/calls/{id}/result`, ручное резюме и текст
для клиента, повтор анализа известного demo, снимок пользовательских настроек.
Провайдер настоящей LLM остался disabled; произвольный или изменённый demo-текст
возвращает 503 `provider_unavailable`.

**Малые проверки:** 9 unit-проверок общего result-набора прошли; PostgreSQL-тест
инициализации всех 24 fixtures и жизненного цикла результата прошёл (1 тест).
Ruff проверяет добавленные модули без замечаний.

**Проблемы → решение:** fixture никогда не используется для произвольного текста;
проверяются scenario, текст, speaker, дата/зона звонка. Повторный анализ создаёт
новые предложения и сохраняет вручную исправленное резюме.

**Приёмка:** demo отмечено synthetic/text_only/no_real_audio; confidence неизвестна,
accuracy не заявляется; резюме сохраняется новой ревизией; клиенту автоматически
ничего не отправляется. Fixtures написаны Codex и ожидают проверки человеком.
