# Этап 4 — звонки и загрузка

**Статус: готово для MVP.** Multipart upload с согласием/датой/зоной звонка,
зашифрованный оригинал, demo-create, карточки/списки звонков, приватный audio Range.
Демо использует текстовые fixtures и не подменяет реальную запись.

**Малые проверки:** 3 audio-unit и 4 PostgreSQL audio/job теста прошли. Проверено:
повтор upload возвращает тот же call, другой payload с ключом даёт 409, хранится
один зашифрованный asset; byte Range/suffix/416; чужому owner — 404; ciphertext
после порчи не читается, файл имеет права 0600, path traversal отклонён.

**Проблемы → решение:** недоступный decoder даёт явную ошибку; поправлены MIME
для FLAC/AAC. Метаданные не заменяют проверку содержимого: локальные быстрые тесты
подменяют probe, реальный ffmpeg проверяется отдельно при сборке контейнера.

**Приёмка:** право обработки требуется; файл ограничен по размеру/длительности;
имя файла не выбирает путь; секретный storage key не возвращается в карточке.
На этом этапе настоящий ASR отключён, после загрузки доступен ручной текст.
