# Этап 11 — напоминания

**Сделано:** политика enabled/offset_minutes/timezone/date_only_time/quiet_hours;
date-only имеет явно настроенное время, default09:00, с выбранными offsets.
При принятии/переносе создаётся расписание; старые reminders отменяются.
Done/cancelled/unconfirm/deleted выключают расписание. Worker сохраняет внутренние
notifications; просмотр/read/version защищены owner и CSRF. В уведомлениях нет
копии расшифровки; браузер может быть закрыт.

Unknown due, неоднозначный срок, нерешённое условие/участники не запускают доставку.
Перед срабатыванием проверяется актуальная версия Agreement и состояние Call;
deduplication_key предотвращает повтор.

**Маленькая проверка:** PostgreSQL подтверждает один notification при двух ticks,
отмену stale revision; unit test проверяет quiet hours через полночь. Общий
набор stages 9–11 — 16 тестов, Ruff проходит.

**Проблема → решение:** quiet hours могут свести два смещения к одному времени;
вместо ошибки unique constraint дублирующий reminder отменяется. Несколько
прошедших смещений также объединяются в одно немедленное уведомление.

**Приёмка:** повтор tick не дублирует notification; перенос/выполнение отменяют
старое расписание; notification остаётся в БД до следующего входа/read.

**Оценка:** нормально для MVP. Email/SMS/push не реализованы. Изменённая политика
применяется к следующему изменению Agreement; quiet_hours/enabled также проверяются
непосредственно worker перед доставкой.
