# Этап 5 — очередь и подготовка

**Статус: готово для MVP.** PostgreSQL jobs, lease/heartbeat, attempt/backoff,
отдельная вычислительная стадия, cancel/retry и явный blocked перед отключённым ASR.
Подготовка приводит аудио к 16 kHz mono PCM и отклоняет близкий к нулю сигнал.

**Малые проверки:** 4 PostgreSQL audio/job теста прошли, включая перехват истёкшего
lease с attempt=2, cancel во время подготовки и истечение lease до commit. В двух
последних случаях derived asset не сохраняется; выдуманной расшифровки нет.

**Проблемы → решение:** унифицирован порядок блокировок Call → Job → Asset, чтобы
worker не конфликтовал с cancel/delete; результат требует текущий token и ещё
действующий lease; отсутствие expires_at не вызывает ошибку. Missing ffmpeg
возвращает `decoder_unavailable` вместо трёх бессмысленных повторов.

**Приёмка:** I/O не держит вычислительную транзакцию, попытки ограничены, отменённый
звонок не оживает поздним результатом. Реального VAD/ASR пока нет; текущая проверка
тишины не заявляется распознаванием речи.
