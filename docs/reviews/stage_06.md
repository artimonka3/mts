# Этап 6 — расшифровки и говорящие

**Статус: готово для MVP без ASR.** GET расшифровки и PATCH ручного импорта/правок,
неизменяемые ревизии, назначение speaker → participant, пары временных отметок.
Пустую расшифровку можно сохранить; текстовое демо не получает выдуманные timestamps.

**Малые проверки:** проверки пары/порядка timestamps, Unicode span и точного demo-текста
прошли в наборе `test_results_contract.py` (9 тестов всего). На PostgreSQL созданы 24 демо,
затем транзакция откатена; новая расшифровка оставляет старый текст и отмечает прежние
договорённости `requires_recheck` (1 интеграционный тест общего сценария).

**Проблемы → решение:** повтор position/segment_id отклоняется; чужой participant
отклоняется; устаревший call.version даёт 409. Локальный доступ к PostgreSQL требовал
разрешения sandbox, после разрешения тест прошёл.

**Приёмка:** новая ревизия создаётся вместо перезаписи; чужие источники не выдаются;
истёкший текст даёт 410. Реальный ASR и диаризация отключены — это ожидаемое
ограничение MVP, не успешное распознавание.
